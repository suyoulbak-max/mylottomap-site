수집 주기와 업데이트

  • 당첨 결과는 추첨 후 공식 자료를 확인하고 검증을 통과한 데이터만 반영합니다. 화면의 마지막 확인 시각을 기준으로 읽어 주세요.
  • 추첨 결과가 발표되지 않은 회차는 만들지 않고 결과 대기로 표시합니다.
  • 가져오기나 검증에 실패하면 마지막 정상 데이터를 그대로 두고 화면에 업데이트 지연을 표시합니다.
  • 판매점 목록은 공공데이터포털 자료의 갱신 주기(연 단위)에 맞춰 반영합니다.

검증 절차

  1. 번호가 1~45 범위인지, 본번호 6개가 서로 다른지, 보너스 번호가 본번호와 겹치지 않는지 검사합니다.
  2. 회차 번호 중복과 추첨일 형식(연도-월-일)을 검사합니다.
  3. 당첨금·당첨자 수는 확인되지 않은 값(미확보)과 실제 0을 구분해 저장합니다.
  4. 이미 저장된 회차와 값이 다르면 덮어쓰지 않고 중단해 원인을 확인합니다.
  5. 모든 검사를 통과한 경우에만 공개 데이터를 교체합니다.

집계 기간과 통계의 한계

  • 당첨 결과·번호 통계·내 번호 당첨 확인은 같은 검증 데이터를 사용합니다. 현재 범위: 533회 ~ 1245회 중 검증된 713개 회차.
  • 번호 통계는 화면에 표시된 분석 회차 수만큼의 기록으로 계산합니다. 회차 수가 적으면 번호별 차이가 우연에 크게 좌우됩니다.
  • 매 회차 추첨은 이전 결과와 독립이므로, 과거에 자주 나왔거나 오래 나오지 않은 번호가 다음 회차에 더 잘 나온다는 근거는 없습니다.
  • 판매점 배출 이력 집계 기간: 625회 ~ 1245회.

배출 횟수를 당첨률로 해석하지 않는 이유

판매점의 1·2등 배출 횟수는 그 판매점에서 팔린 복권 수에 크게 좌우됩니다. 판매량이 많으면 같은 확률에서도 당첨이 더 많이 나옵니다. 마이로또맵은 판매점별 판매량 자료를 가지고 있지 않으므로 배출 횟수를 판매점의 당첨 확률·당첨률로 바꾸어 표시하지 않으며, 특정 판매점에서 사면 당첨 가능성이 높아진다고 안내하지 않습니다. 자세한 내용은 명당 배출 횟수를 해석할 때 알아둘 점을 참고하세요.

인터넷 구매(동행복권 사이트) 당첨 1등 130건 · 2등 823건은 실제 판매점이 없어 지도·판매점 집계에서 제외했습니다.

판매점 좌표

지도 핀은 출처와 확인 시각이 기록된 좌표가 있는 판매점에만 표시합니다. 현재: 공개 판매점 9612곳 중 좌표 확인 9611곳, 좌표 미확보 1곳.

지도 서비스의 주소 검색 결과는 이용 조건상 저장해 다시 쓸 수 없어 좌표 출처로 사용하지 않습니다. 좌표가 없는 판매점은 지도 핀 없이 주소와 외부 길찾기 링크로 제공합니다.
