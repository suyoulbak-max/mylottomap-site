마이로또맵 번호 생성·저장 사용법: 무작위 생성과 조건 설정

작성 마이로또맵 데이터팀작성일 2026-10-08수정일 2026-11-25

마이로또맵의 번호 생성은 로또 6/45 규칙에 맞춰 1부터 45까지의 번호 중 서로 다른 6개를 무작위로 고르는 도구입니다. 회원가입 없이 바로 쓸 수 있고, 만든 번호는 이 브라우저의 내 번호에 저장해 추첨 뒤 결과와 비교할 수 있습니다. 이 글은 기본 생성부터 조건 설정, 저장, 오류 해결까지 화면 순서대로 설명합니다.

번호 생성기는 번호를 어떻게 고르나요?

조건을 비워 두면 1~45의 45개 번호가 모두 같은 가능성으로 뽑히고, 서로 다른 6개가 한 게임이 됩니다. 결과는 오름차순으로 표시되며, 이용자가 고르지 않은 숨은 조건은 넣지 않습니다.

  • 번호 생성 화면에서 만들 게임 수를 1~5게임 중에서 고릅니다.
  • 생성 버튼을 누르면 게임마다 6개 번호가 오름차순으로 표시됩니다.
  • 연속 번호 제외나 합계 제한 같은 조건은 이용자가 직접 고른 경우에만 적용합니다.
  • 생성된 게임마다 홀짝 개수, 합계, 가장 길게 이어진 연속 번호 개수가 함께 표시됩니다.

여기서 만든 번호는 화면 위의 기록일 뿐 구매 내역이 아닙니다. 실제로 발행된 복권의 번호는 복권 실물로 따로 확인해야 합니다.

포함·제외 번호는 어떻게 입력하나요?

꼭 넣을 번호는 '포함'에 최대 6개, 뺄 번호는 '제외'에 여러 개 넣을 수 있습니다. 번호는 쉼표나 띄어쓰기로 구분하고, 범위 밖 번호나 두 칸에 동시에 넣은 번호가 있으면 생성하지 않고 안내합니다.

조건입력 규칙이런 경우 생성하지 않고 안내합니다
포함 번호최대 6개7개 이상 입력, 범위(1~45) 밖 번호
제외 번호여러 개 가능같은 번호를 포함과 제외에 모두 입력
조합 가능 여부남은 번호로 6개를 채울 수 있어야 함제외 번호가 너무 많아 6개를 만들 수 없음

포함 번호를 k개 정하면 나머지 (6 − k)자리를 남은 (45 − k)개 번호에서 고르므로, 만들어질 수 있는 조합 수는 C(45 − k, 6 − k)로 줄어듭니다.

범위가 좁아질 뿐, 남은 조합 하나하나의 1등 확률은 그대로 8,145,060분의 1입니다. 조건은 이용자의 취향을 반영할 뿐이며 당첨 확률을 높이지 않습니다. 그 이유는 로또 당첨 확률과 번호 조합의 관계에서 설명합니다.

홀짝·합계·연속 조건을 켜면 무엇이 달라지나요?

세 조건은 모두 선택 사항이며 비워 두면 제한하지 않습니다. 조건을 고르면 그에 맞는 조합 수와 전체 8,145,060개 중 비율이 바로 표시되고, 생성기는 그 조합들 가운데 하나를 같은 확률로 고릅니다.

조건고르는 방법예
홀짝 비율홀0 : 짝6 ~ 홀6 : 짝0 중 여러 개 선택홀3 : 짝3과 홀4 : 짝2만 허용
번호 합계 범위최솟값·최댓값(21~255), 한쪽만 입력 가능121 ~ 160

아래 값은 8,145,060개 조합을 모두 직접 센 결과입니다(마이로또맵 데이터팀 계산, Python).

'연속 번호 없음'이 절반에도 못 미친다는 점이 눈에 띕니다. 무작위로 고른 6개 중 절반 이상에는 7, 8처럼 이어진 번호가 한 쌍 이상 들어 있으므로, 연속 번호가 섞인 결과는 드문 일이 아닙니다.

  • 확보된 당첨 번호 중 몇 회차가 같은 조건에 맞았는지도 함께 보여 줍니다. 표본이 적으면 이 비율과 전체 조합 비율은 크게 다를 수 있으며, 과거 일치 비율만으로 다음 회차의 유리한 조건을 고를 수는 없습니다.
  • 조건에 맞는 조합이 하나도 없으면 생성하지 않고 이유를 알려 드립니다.

홀짝·합계 비율의 이론값은 홀짝 비율·번호 합계 통계 읽는 법에 정리했습니다.

대상 회차는 왜 생성 전에 확인해야 하나요?

생성 결과에는 생성 당시의 대상 회차와 조건이 함께 묶여 기록되기 때문입니다. 생성한 뒤 입력칸의 회차만 바꿔도 이미 만든 번호의 대상 회차는 그대로이므로, 다른 회차로 저장하려면 회차를 바꾸고 다시 생성해야 합니다.

  • 화면 위쪽에는 '제○○○○회 · 날짜(토) 추첨 예정' 형식으로 대상 회차가 표시됩니다.
  • 저장하면 대상 회차, 번호 6개, 저장 시각이 함께 기록됩니다.
  • 번호 복사 버튼으로 생성 결과를 클립보드에 복사할 수도 있습니다.
  • 이미 산 번호는 내 번호 화면의 직접 번호 등록에서 같은 규칙으로 입력할 수 있습니다.

저장한 번호는 어디에 남나요?

지금 쓰는 기기 브라우저의 로컬 저장소에만 남고 서버로 전송되지 않습니다. 그래서 다른 기기나 다른 브라우저에서는 보이지 않으며, 브라우저의 사이트 데이터를 지우면 저장한 번호도 함께 사라집니다.

저장이 막힌 환경에서는 저장 실패 안내가 나오지만 번호 생성은 계속 이용할 수 있습니다. 휴대폰을 바꾸거나 브라우저를 정리할 계획이라면, 그 전에 번호와 대상 회차를 복사해 따로 적어 두는 편이 안전합니다.

지역·기간 참고 정보는 생성 번호와 어떤 관계인가요?

관계가 없습니다. 번호 생성 아래의 관심 지역과 조회 기간은 판매점 이력과 전국 번호 통계를 바꾸는 참고 정보일 뿐이며, 지역이나 기간을 바꿔도 생성되는 번호와 그 확률은 달라지지 않습니다.

  1. 방문할 지역을 고릅니다. 전국 번호 통계는 전국 추첨 결과이므로 지역 선택과 무관합니다.
  2. 최근 10·20·50회 또는 확보된 전체 기간을 고릅니다. 선택지는 확보 범위에 따라 달라지고, 실제 집계된 회차 수를 함께 확인해야 합니다.
  3. 판매점의 1등·2등 건수와 집계 기간을 읽고 지도 링크로 이동합니다. 같은 기간의 기록을 이어 볼 수 있습니다.

판매점 목록은 1등 배출 수가 많은 순으로, 같으면 2등 배출 수, 그다음 최근 당첨 회차 순으로 정렬됩니다. 흔히 '명당'이라 부르는 곳은 이렇게 배출 기록이 많은 판매점을 뜻하며, 판매량이 많아 배출도 많아진 경우(판매량 효과)가 대부분입니다. 자세한 해석은 명당 배출 횟수를 해석할 때 알아둘 점을 참고하세요.

가장 많이·적게 나온 번호는 동률을 모두 표시한 과거 기록입니다. 판매점 배출 횟수도 다음 당첨 가능성을 의미하지 않습니다. 구매 요일·시간 자료가 없으므로 최적 구매 시간은 제공하지 않습니다.

입력 오류가 나면 어떻게 고치나요?

오류 안내는 대부분 조건끼리 부딪히거나 범위를 벗어났을 때 나옵니다. 포함·제외 충돌, 합계 최솟값과 최댓값의 뒤바뀜, 모든 조건을 만족하는 조합이 0개인 경우가 대표적이며, 조건을 하나씩 풀면 원인을 찾을 수 있습니다.

입력 상황결과와 해결 방법
포함 7, 제외 13, 나머지 조건 없음각 게임에 7이 들어가고 13은 빠집니다. 나머지 번호는 실행할 때마다 달라집니다.
포함 7, 제외 7충돌 오류입니다. 한쪽에서 7을 지운 뒤 생성하세요.
포함 1 2 3 4 5 6, 다른 조건 없음가능한 조합은 이 1개뿐입니다. 여러 게임을 선택하면 모든 게임이 같은 조합으로 나옵니다.
포함 1 3 5 7 9, 홀6 : 짝0만 선택마지막 한 자리는 남은 홀수 18개 중 하나여야 하므로 가능한 조합은 18개뿐입니다.
제외 번호 40개 이상남은 번호가 5개 이하라 6개를 채울 수 없습니다. 화면에는 "선택 가능한 번호가 ○개로 부족합니다. 제외 번호를 줄여 주세요."라고 나옵니다.
합계 최솟값이 최댓값보다 큼범위를 바로잡으세요. 합계 자체의 가능한 범위는 21~255입니다.
조건에 맞는 조합 수가 0포함·제외, 홀짝, 합계, 연속 조건을 하나씩 풀어 보세요.

저장이 실패하면 먼저 복사 기능으로 번호를 별도로 보관하고 브라우저의 사이트 데이터 허용 설정을 확인하세요. 기존 번호가 필요하다면 사이트 데이터를 지우기 전에 별도 보관해야 합니다. 복사도 막힌 환경이면 화면의 번호와 대상 회차를 직접 기록할 수 있습니다.

추첨이 끝나면 저장한 번호는 어떻게 확인하나요?

추첨 뒤에는 내 번호가 저장된 대상 회차의 당첨 번호와 자동으로 비교합니다. 결과가 아직 반영되지 않았으면 결과 대기로 보이고, 실제 당첨 여부와 지급은 동행복권 공식 결과와 복권 실물로 확인해야 합니다.

등수 판정 기준과 결과 대기의 뜻은 내 번호 당첨 확인 방법에 정리했습니다.

자주 묻는 질문

번호 생성기가 만든 번호는 당첨 가능성이 더 높은가요?

아닙니다. 번호 생성기는 1~45에서 서로 다른 6개를 무작위로 고를 뿐이며, 어떤 조합이든 1등 확률은 8,145,060분의 1로 같습니다. 조건은 당첨 확률을 높이지 않고 고르는 범위만 좁힙니다.

회원가입 없이 번호를 저장할 수 있나요?

네. 저장한 번호는 지금 쓰는 기기 브라우저의 로컬 저장소에만 남고 서버로 보내지 않습니다. 그래서 다른 기기나 다른 브라우저에서는 보이지 않고, 사이트 데이터를 지우면 함께 사라집니다.

생성한 뒤 대상 회차를 바꾸면 저장 회차도 바뀌나요?

바뀌지 않습니다. 저장에는 생성 당시의 대상 회차가 쓰입니다. 다른 회차로 저장하려면 입력칸의 회차를 바꾼 뒤 번호를 다시 생성해야 합니다.

관심 지역을 바꾸면 생성 번호도 달라지나요?

달라지지 않습니다. 관심 지역과 조회 기간은 아래쪽 판매점 이력과 번호 통계에만 적용되며, 번호 생성 조건과는 별개입니다.
