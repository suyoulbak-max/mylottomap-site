마이로또맵 번호 생성·저장 사용법

작성일 2026-10-08수정일 2026-10-09

마이로또맵의 번호 생성은 로또 6/45 규칙에 맞춰 1부터 45까지의 번호 중 서로 다른 6개를 무작위로 고르는 도구입니다. 회원가입 없이 바로 쓸 수 있고, 만든 번호는 이 브라우저의 내 번호에 저장해 추첨 뒤 결과와 비교할 수 있습니다.

1. 기본 생성

  1. 번호 생성 화면에서 생성할 게임 수를 1~5게임 중에서 고릅니다.
  2. 생성 버튼을 누르면 게임마다 6개 번호가 오름차순으로 표시됩니다.
  3. 아무 조건도 넣지 않으면 45개 번호가 모두 같은 가능성으로 선택됩니다. 연속 번호 제외나 합계 제한 같은 숨은 조건은 넣지 않으며, 이런 조건은 이용자가 직접 고른 경우에만 적용합니다.

2. 포함·제외 번호 지정

원하는 번호를 꼭 넣거나 빼고 싶을 때만 조건을 입력합니다. 번호는 쉼표나 띄어쓰기로 구분합니다.

조건입력 규칙이런 경우 생성하지 않고 안내합니다
포함 번호최대 6개7개 이상 입력, 범위(1~45) 밖 번호
제외 번호여러 개 가능같은 번호를 포함과 제외에 모두 입력
조합 가능 여부남은 번호로 6개를 채울 수 있어야 함제외 번호가 너무 많아 6개를 만들 수 없음

조건은 이용자의 취향을 반영할 뿐이며 당첨 확률을 높이지 않습니다. 모든 6개 조합의 1등 확률은 똑같이 8,145,060분의 1이고, 그 이유는 로또 당첨 확률과 번호 조합의 관계에서 설명합니다.

3. 홀짝·합계·연속 번호 조건

포함·제외 외에 다음 조건을 골라 쓸 수 있습니다. 모두 선택 사항이며, 비워 두면 제한하지 않습니다.

조건고르는 방법예
홀짝 비율홀0 : 짝6 ~ 홀6 : 짝0 중 여러 개 선택홀3 : 짝3과 홀4 : 짝2만 허용
번호 합계 범위최솟값·최댓값(21~255), 한쪽만 입력 가능121 ~ 160
연속 번호제한 없음, 연속 번호 없음, 최대 2개, 최대 3개최대 2개면 7, 8은 되지만 7, 8, 9는 제외
  • 조건을 바꾸면 조건에 맞는 조합 수와 전체 8,145,060개 중 비율이 바로 표시됩니다. 예를 들어 홀3 : 짝3만 고르면 2,727,340개(약 33.5%)입니다.
  • 확보된 당첨 번호 중 몇 회차가 같은 조건에 맞았는지도 함께 보여 줍니다. 표본이 적으면 이 비율과 전체 조합 비율은 크게 다를 수 있습니다. 과거 일치 비율만으로 다음 회차의 유리한 조건을 고를 수는 없습니다.
  • 번호는 조건에 맞는 조합을 모두 센 뒤 그중 하나를 같은 확률로 골라 만듭니다. 조건에 맞는 조합이 하나도 없으면 생성하지 않고 이유를 알려 드립니다.
  • 생성된 게임마다 홀짝 개수, 합계, 가장 길게 이어진 연속 번호 개수가 함께 표시됩니다.

홀짝·합계 비율의 이론값은 홀짝 비율·번호 합계 통계 읽는 법에 정리했습니다.

4. 대상 회차를 확인하고 저장

  • 생성 전에 대상 회차를 확인하세요. 생성 결과에는 생성 당시의 대상 회차와 조건이 표시되고, 저장할 때도 그 회차를 사용합니다. 생성 후 입력칸의 회차만 바꾸어도 이미 만든 번호의 대상 회차는 바뀌지 않습니다. 다른 회차로 저장하려면 회차를 바꾼 뒤 다시 생성하세요.
  • 저장하면 대상 회차, 번호 6개, 저장 시각이 함께 기록됩니다.
  • 번호 복사 버튼으로 생성 결과를 클립보드에 복사할 수도 있습니다.
  • 이미 산 번호는 내 번호 화면의 직접 번호 등록에서 같은 규칙으로 입력할 수 있습니다.

5. 저장 위치에 대한 안내

저장한 번호는 이 기기 브라우저의 로컬 저장소에만 남고 서버로 전송되지 않습니다. 그래서 다른 기기나 다른 브라우저에서는 보이지 않으며, 브라우저의 사이트 데이터를 지우면 함께 사라집니다. 저장이 막힌 환경에서는 저장 실패 안내가 나오지만 번호 생성은 계속 이용할 수 있습니다.

6. 지역·기간 참고 정보를 사용하는 순서

번호 생성 아래의 관심 지역과 조회 기간은 판매점 이력과 전국 번호 통계를 바꿉니다. 번호 생성 조건과는 별개이며 지역을 바꿔도 생성 번호가 바뀌지 않습니다.

  1. 방문할 지역을 고릅니다. 전국 번호 통계는 전국 추첨 결과이므로 지역 선택과 무관합니다.
  2. 최근 10·20·50회 또는 확보된 전체 기간을 고릅니다. 선택지는 확보 범위에 따라 달라지고, 실제 집계된 회차 수를 함께 확인해야 합니다.
  3. 판매점의 1등·2등 건수와 집계 기간을 읽고 지도 링크로 이동합니다. 같은 기간의 기록을 이어 볼 수 있습니다.

가장 많이·적게 나온 번호는 동률을 모두 표시한 과거 기록입니다. 판매점 배출 횟수도 다음 당첨 가능성을 의미하지 않습니다. 구매 요일·시간 자료가 없으므로 최적 구매 시간은 제공하지 않습니다.

7. 입력 오류를 해결하는 예

입력 상황결과와 해결 방법
포함 7, 제외 13, 나머지 조건 없음각 게임에 7이 들어가고 13은 빠집니다. 나머지 번호는 실행할 때마다 달라집니다.
포함 7, 제외 7충돌 오류입니다. 한쪽에서 7을 지운 뒤 생성하세요.
포함 1 2 3 4 5 6, 다른 조건 없음가능한 조합은 이 1개뿐입니다. 여러 게임을 선택해도 같은 조합이 나올 수 있습니다.
합계 최솟값이 최댓값보다 큼범위를 바로잡으세요. 합계 자체의 가능한 범위는 21~255입니다.
조건에 맞는 조합 수가 0포함·제외, 홀짝, 합계, 연속 조건을 하나씩 풀어 보세요.

저장이 실패하면 먼저 복사 기능으로 번호를 별도로 보관하고 브라우저의 사이트 데이터 허용 설정을 확인하세요. 기존 번호가 필요하다면 사이트 데이터를 지우기 전에 별도 보관해야 합니다. 복사도 막힌 환경이면 화면의 번호와 대상 회차를 직접 기록할 수 있습니다.
