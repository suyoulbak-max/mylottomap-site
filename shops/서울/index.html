표에 있는 25개 구는 어떻게 찾아가나요?

서울은 25개 자치구로 나뉘고, 이 페이지의 표도 구마다 한 줄씩 보여 줍니다. 구 이름을 누르면 그 구의 판매점 목록이 열리고, 목록은 1등 배출 수, 2등 배출 수, 최근 당첨 회차 순서로 정렬됩니다.

판매점마다 '현재 판매점 목록 확인' 또는 '현재 목록에서 확인 안 됨(폐업·이전 가능)' 표시가 붙습니다. 오래된 기록 가운데는 문을 닫거나 옮긴 가게도 있으니, 방문 전에는 외부 지도로 영업 여부를 다시 확인하세요.

역 앞이나 번화가 판매점에 1등이 몰리는 것은 운 때문인가요?

운보다는 판매량 차이로 보는 것이 자연스럽습니다. 오가는 사람이 많은 곳의 판매점은 하루에 팔리는 게임 수가 많고, 게임 하나하나의 당첨 확률은 어디서나 같으니 팔린 만큼 당첨 기록도 늘어납니다.

'명당'은 그렇게 배출 기록이 많이 쌓인 판매점을 부르는 이름일 뿐이며, 판매점이나 구매 시간 같은 조건은 당첨 확률을 높이지 않습니다. 마이로또맵은 판매점별 판매량 자료가 없어 배출 횟수를 당첨률로 바꿔 보여 주지 않습니다(집계 기준).

서울 로또 명당은 어디인가요?

이 사이트에서 '명당'은 1·2등이 나온 기록이 많은 판매점을 가리킵니다. 서울에서는 스파(1등 53건), 로또킹(1등 24건), 잠실매점(1등 22건)의 1등 기록이 많고, 구별 표를 누르면 각 자치구의 전체 판매점 목록을 볼 수 있습니다.

서울에서 1등이 많이 나온 판매점은 정말 운이 좋은 곳인가요?

그렇게 해석하기 어렵습니다. 유동 인구가 많은 곳의 판매점은 많이 팔고, 많이 판 만큼 당첨 게임도 자주 나옵니다. 게임 하나의 당첨 확률은 어디서 사도 같으며, 판매점 같은 조건은 당첨 확률을 높이지 않습니다.

판매점 목록의 '현재 목록에서 확인 안 됨'은 무슨 뜻인가요?

동행복권 판매점 목록에서 같은 주소를 찾지 못했다는 표시입니다. 문을 닫았거나 다른 곳으로 옮겼을 수 있으니, 방문하려면 외부 지도에서 현재 영업 여부를 다시 확인하세요.

판매량 정보 없이 수집 기간의 1·2등 배출 횟수만 집계했습니다. 배출 횟수는 판매점별 당첨 확률이나 명당 효과를 뜻하지 않습니다.
