전국 로또 명당, 당첨 결과와 내 번호를 한곳에서

서비스 목적

마이로또맵은 로또 6/45 이용자가 공식 출처로 확인한 당첨 결과와 판매점 정보를 쉽게 찾고, 직접 고른 번호를 저장해 추첨 뒤 결과를 확인할 수 있도록 만든 무료 서비스입니다. 회원가입 없이 이용합니다.

주요 기능

  • 명당맵

    지역·상호로 판매점을 찾고 확인된 1·2등 배출 이력을 지도와 목록으로 봅니다.

  • 당첨 결과

    회차별 당첨 번호, 보너스 번호, 등수별 당첨금과 당첨자 수를 확인합니다.

  • 번호 통계

    검증된 회차에서 번호별 출현 횟수, 미출현 기간, 홀짝·합계 분포를 계산합니다.

  • 번호 생성

    1~45에서 중복 없이 6개를 무작위로 고르고, 원하면 포함·제외 번호를 지정합니다.

  • 내 번호

    대상 회차별로 번호를 브라우저에 저장하고 추첨 결과와 비교합니다.

  • 가이드

    당첨 확률, 통계 읽는 법, 명당 배출 횟수 해석을 설명합니다.

번호 생성은 무작위 선택이며 당첨 확률을 높이거나 당첨을 예측하지 않습니다.
