마이로또맵 소개

전국 판매점의 1·2등 배출 기록, 당첨 결과와 내 번호를 한곳에서 확인합니다.

마이로또맵은 어떤 서비스인가요?

마이로또맵은 로또 6/45 이용자가 공식 출처로 확인한 당첨 결과와 판매점 정보를 쉽게 찾고, 직접 고른 번호를 저장해 추첨 뒤 결과를 확인할 수 있도록 만든 무료 서비스입니다. 회원가입 없이 이용합니다.

누가, 왜 만들었나요?

마이로또맵의 운영자는 '마이로또맵'이고, 데이터 수집·검증과 가이드 작성은 '마이로또맵 데이터팀'이 맡습니다. 공식 당첨 결과와 당첨 판매점 기록은 서로 다른 화면에 있어 함께 보기 어렵습니다. 이 둘을 출처와 함께 한곳에서 보여 주려고 만들었습니다.

로또 이용자가 자주 찾는 정보는 세 가지입니다. 이번 회차 당첨 번호, 근처 판매점의 당첨 기록, 그리고 내가 고른 번호의 결과입니다. 마이로또맵은 이 세 가지를 한 사이트에서 이어 볼 수 있게 묶었습니다.

정보를 모으는 데에는 몇 가지 원칙을 둡니다.

  • 공식 출처에서 확인한 값만 보여 줍니다.
  • 보여 주는 결과에는 출처와 확인 시각을 기록합니다.
  • 확률과 통계는 과장하지 않고, 숫자가 뜻하지 않는 것도 함께 적습니다.

가이드는 공식 자료를 그대로 옮기지 않습니다. 당첨 확률, 통계 읽는 법, 배출 횟수 해석처럼 숫자를 읽을 때 필요한 설명을 데이터팀이 직접 정리합니다.

어떤 기능을 제공하나요?

판매점 지도, 회차별 당첨 결과, 번호 통계, 무작위 번호 생성, 내 번호 저장과 결과 비교, 가이드를 제공합니다. 모두 무료이며 회원가입이 필요 없습니다. 번호 생성은 무작위 선택이며 당첨 확률을 높이거나 당첨을 예측하지 않습니다.

  • 명당맵: 지역·상호로 판매점을 찾고 확인된 1·2등 배출 이력을 지도와 목록으로 봅니다.
  • 당첨 결과: 회차별 당첨 번호, 보너스 번호, 등수별 당첨금과 당첨자 수를 확인합니다.
  • 번호 통계: 검증된 회차에서 번호별 출현 횟수, 미출현 기간, 홀짝·합계 분포를 계산합니다.
  • 번호 생성: 1~45에서 중복 없이 6개를 무작위로 고르고, 원하면 포함·제외 번호를 지정합니다.
  • 내 번호: 대상 회차별로 번호를 브라우저에 저장하고 추첨 결과와 비교합니다.
  • 가이드: 당첨 확률, 통계 읽는 법, 명당 배출 횟수 해석을 설명합니다.

명당맵에서 말하는 '명당'은 1·2등 배출 기록이 많은 판매점을 뜻합니다. 배출이 많은 것은 대개 그 판매점에서 팔린 복권이 많기 때문입니다(판매량 효과). 그 판매점에서 사면 당첨 가능성이 높아진다는 뜻이 아닙니다. 자세한 설명은 명당 배출 횟수를 해석할 때 알아둘 점에 있습니다.

현재 데이터 범위는 어디까지인가요?

당첨 결과는 1회부터 공식 결과를 확인하고 검증을 통과한 회차까지 다룹니다. 판매점 1·2등 배출 이력은 262회부터의 기록입니다. 정확한 회차 범위와 판매점 수, 마지막 확인 시각은 아래 수치와 데이터·통계 설명 화면에 표시됩니다.

데이터는 어디서 가져오고 어떻게 검증하나요?

당첨 결과와 판매점 배출 이력은 동행복권 공식 화면에서, 판매점 주소 대조 자료는 공공데이터포털 복권판매점 목록에서 가져옵니다. 공식 API는 쓰지 않습니다. 결과마다 출처와 확인 시각을 기록하고, 검사를 모두 통과한 데이터만 공개합니다.

당첨 결과를 저장하기 전에 다음을 검사합니다.

  • 번호가 1~45 범위인지, 본번호 6개가 서로 다른지, 보너스 번호가 본번호와 겹치지 않는지
  • 회차 번호가 중복되지 않는지, 추첨일 형식이 맞는지
  • 당첨금·당첨자 수에서 확인되지 않은 값(미확보)과 실제 0을 구분했는지
  • 이미 저장된 회차와 값이 다르지 않은지. 다르면 덮어쓰지 않고 중단해 원인을 확인합니다.

추첨 결과가 발표되지 않은 회차는 만들지 않고 결과 대기로 표시합니다. 가져오기나 검증에 실패하면 마지막 정상 데이터를 그대로 두고 화면에 업데이트 지연을 표시합니다. 판매점 목록은 공공데이터포털 자료의 갱신 주기(연 단위)에 맞춰 반영합니다.

인터넷 구매 당첨은 실제 판매점이 없어 지도와 판매점 집계에서 제외합니다. 지도 핀은 출처와 확인 시각이 기록된 좌표가 있는 판매점에만 표시합니다. 판매점 목록과 일치한다고 해서 현장 영업이 확인된 것은 아닙니다.

잘못된 정보를 발견하면 어떻게 알리나요?

사이트의 문의·오류 제보 양식으로 알려 주세요. 페이지 주소, 회차나 판매점 이름, 틀려 보이는 값과 공식 화면에서 확인한 값을 함께 적어 주시면 공식 출처와 대조하기 쉽습니다. 당첨금 지급처럼 개인 복권에 관한 문의는 동행복권 고객센터로 하셔야 합니다.

제보에 함께 적어 주시면 좋은 내용입니다.

  1. 문제가 보인 페이지 주소
  2. 회차 번호, 또는 판매점 이름과 시도
  3. 마이로또맵에 표시된 값과 공식 화면에서 확인한 값
  4. 공식 화면을 확인한 날짜와 시각

보내 주신 내용은 공식 출처와 다시 대조하는 데 씁니다. 판매점 목록은 공공데이터포털 자료의 갱신 주기에 맞춰 반영하므로, 판매점 폐업이나 이전 제보는 화면에 바로 반영되지 않을 수 있습니다.

마이로또맵은 개별 복권의 당첨 여부나 지급 가능 여부를 판정하지 않습니다. 복권 분실·훼손, 당첨금 수령은 동행복권 고객센터(1588-6450)와 공식 안내를 확인하세요.

마이로또맵이 하지 않는 일은 무엇인가요?

마이로또맵은 복권을 판매하거나 구매를 대신하지 않고, 당첨 번호를 예측하지 않습니다. 번호 생성은 1~45에서 6개를 무작위로 고르는 기능일 뿐이며, 어떤 조건도 당첨 확률을 높이지 않습니다. 동행복권·복권위원회와 관계없는 독립 서비스입니다.

  • 복권을 팔지 않고, 구매를 대행하거나 구매 페이지로 안내하지 않습니다.
  • 다음 회차 번호를 예측하지 않습니다. 매 회차 추첨은 이전 결과와 독립이므로, 번호 통계는 과거 기록을 설명할 뿐입니다.
  • 판매점의 배출 횟수를 당첨 확률이나 당첨률로 바꾸어 표시하지 않습니다. 판매점별 판매량 자료가 없기 때문입니다.
  • 내 번호 저장 기록은 브라우저에 남긴 메모입니다. 복권 구매나 소유를 증명하지 않습니다.
  • 복권은 청소년이 구매할 수 없습니다. 마이로또맵은 미성년자를 대상으로 하지 않습니다.
